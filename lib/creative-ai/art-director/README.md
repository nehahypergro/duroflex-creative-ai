# Art director foundation

Callable CommonJS contract, strict JSON schemas, source-backed knowledge and synthetic examples. No live inference, image collection, retries or downstream calls are implemented. Both continuity and exploration automatically reach Graphic designer together only when their per-placement specifications are ready. Blocking issues retain both identities and route to internal roles, with no intermediate human gate.

```js
const art = require('./lib/creative-ai/art-director');
const fixture = require('./lib/creative-ai/art-director/examples/synthetic');
const input = await fixture.inputExample();
const context = await art.assembleContext(input); // validates upstream, pins placements, decodes references
const output = art.finalizeOutput(fixture.coreExample(context), context);
art.validateOutput(output, context);
```

The schemas are the authoritative field contracts. `input.directorInput/directorOutput` preserve strategist evidence, GET/WHO/TO/BY and exactly two concept cards. `copy` is an interface for exact Copywriter input, not a Copywriter implementation. It has one deck per concept×placement; each field declares text, delivery, proof IDs, mandatory/optional status and lock. All supplied text stays exact even when optional. Changing a deck requires a new upstream revision and new hashes.

`assets` declare ownership, this brand’s identity, source provenance, synthetic status and an embedded raster payload or absolute local path. Resolution checks source accessibility, size bounds and full PNG/JPEG/WebP decoding, then embeds immutable bytes and SHA-256 in handoff packets. Missing locators and URLs remain missing. Ownership declarations are provenance, not independent rights verification. Continuity cannot use external references; exploration can use them only for background/scene/setting/light/camera/texture/mood. They cannot supply text/type/layout/logo/product/identity. No Pinterest image is supplied or collected in this implementation.

`placement-adapter.js` only consumes `placement-knowledge.assembleContext`, preserving pins, source status, rules, unknowns and conflicts. Optional archived/custom `catalog` can be passed to `assembleContext`. Pending selection fabricates no publisher specification. The separately owned placement package is unchanged.

Every specification carries focal communication, concrete scene/composition/hierarchy, image/camera/light, palette/type, exact text positions, logo/product roles, source-status annotations, locked rules, flexible decisions, rationale, dependencies, Copywriter reconciliation and eventual rendered checks. `handoff` is generated deterministically and validated by exact equality. Graphic designer receives whole-static-image instructions; there is no separate compositor.

The synthetic fixture is a color-study planning job, with no actual bottle, logo or font. Real execution must mark those required in the production job rather than treating the fixture as a finished ad. The knowledge pack annotates primary design/perception guidance with authored good/bad decisions and review limits. No expertise, campaign performance, visual quality or actual semantic compliance has been evaluated. Runtime checks cover explicit references and declarations; natural-language contradictions and hidden visual borrowing require qualified review.

Dedicated studio reasoning records `brandGuidelineApplications` as `{ruleId, decision, why}` per layout. Each cited rule must be a locked rule supported by an accessible guideline source in the same input. Website observations and general design principles do not qualify. The saved generation package preserves these applications and the source's draft/coverage limits; the image review displays intended application separately from actual artwork compliance. Legacy packages remain valid and show when no specific explanation was recorded.
