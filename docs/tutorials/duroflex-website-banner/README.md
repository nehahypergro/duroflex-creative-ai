# Duroflex website banner tutorial (sources)

The finished guide is `../duroflex-website-banner-tutorial.pdf` (27 A4 pages, 25 Nov 2026).

## What is here

- `tutorial.html`: the page source, generated by `build.js`. Open it in a browser to read the guide as one long page.
- `build.js`: the page text, the screenshot crops and the numbered markers (in 800-px capture pixels), and the step that prints the PDF with the repository's Chromium (`playwright-core`). It warns when a page's content runs into its footer.
- `mask-screens.js`: turns raw captures into `screens/`. It blurs the signed-in account name in the sidebar and saves compact PNGs (banner and close-ups as JPEG).
- `screens/`: the 43 screenshots and close-ups used in the guide, with the account name already blurred.

## Rebuild

```bash
node docs/tutorials/duroflex-website-banner/build.js
```

To replace screenshots, capture the local Studio at 820 × 740 in the built-in browser and keep the raw files **outside the repository** (they show the account name). Then:

```bash
node docs/tutorials/duroflex-website-banner/mask-screens.js <raw folder>
```
