# Complete artwork and editable text — 2 November 2026

New Studio and advanced editable generation requests use `composedTextVersion: 1` alongside the existing editable composition contract. The version is stored in the intake. Already-saved jobs retain their renderer and source history.

The shared Duroflex/Sleepyhead engine now:

1. Generates complete artwork with exact embedded campaign copy and the scoped brand's final art/typography plan. Native publisher fields stay outside the artwork; approved campaign logos are composed separately.
2. Measures each exact copy field through local Apple Vision OCR, including substring bounds that exclude decorative arrows. Reconstructs its text using the selected actual brand font. This is a measured font approximation, not recovery of the image model's original font.
3. Saves an immutable source-bound typography checkpoint. Automatic fitting is disabled for this version, and automatic review corrections cannot alter its objects/fonts. Users can still explicitly edit the resulting canvas.
4. Builds a colour-sensitive letter mask and sends it with a second image edit. PNG masks work in both multipart and production CDN/JSON transport. Mask hashes bind cache identity and usage receipts. The brand-scoped wrapper verifies source/mask bytes against the same saved job/unit before dispatch.
5. Restores original pixels outside the mask and harmonically matches colour offsets inside its boundaries. Padding accommodates API dimensions without rescaling repair pixels; padding is cropped after repair.
6. Checks the empty background for residual campaign text, renders the frozen text and approved logo, and runs the existing single visual review. Defects remain visible and outputs still require review; no silent font reduction or readiness upgrade occurs.

Image-only placements require one image call and skip text separation. Placements with embedded text normally require two. Existing two-image-per-unit budgets cover these steps; receipts remain distinct. Historical one-image flow samples are excluded from new-flow cost estimates rather than reused as misleading quotes.

## User-visible result

Only the final composed image with text is published as an image result/artifact. Source artwork, removal mask, text-free background and reconstruction checkpoints stay internal; no intermediate preview or download is added. The final editor still uses its background asset beneath editable text as usual.

## Failure and recovery

The full artwork, raw masked output, mask, frozen document, clean background and repair evidence are kept separately. Request checkpoints reject changed source/layout identity. Saved image responses avoid new calls on resume. Missing/ambiguous OCR, overlapping copy/protected regions, uncertain ink, unsupported dimensions, oversized masks or residual lettering stop separation with the original saved. Apple Vision currently requires macOS; no unsupported-platform paid generation is dispatched by this path. No automatic substitute flow or additional paid retry was added.

The user-approved invariant is typography stability during repair. The first reconstruction's font sizes and positions are frozen. Very long replacement copy still needs explicit user adjustment; arbitrary reflow is not promised. Clean OCR is not proof of visual perfection, and repaired texture is reconstructed rather than recovered ground truth.

## Separate lines and email fit recovery — 2 November 2026

New composed jobs pin `composedLineVersion: 1` and use reconstruction v4. Each measured text line becomes an independent Fabric text object with the saved field ID and immutable zero-based `lineIndex`/`lineCount`. Saved-copy and wording-agreement checks reassemble the complete field in that order; missing, duplicated or unbound lines remain invalid. Editor changes preserve these bindings. Glyph height and placement are calibrated per line using the same approved font file, with uniform glyph scaling and bounded spacing calibration. The user approved a maximum 5% font-size approximation from the source-derived estimate; calibrated typography freezes before masked repair. Font recovery remains approximate.

Copy-fit recovery now handles returned blocked specifications as well as fit exceptions. A copy/layout dependency receives at most one upstream revision before dispatch. Failure after that revision stays blocked. New copy lock authority v1 derives exact locks from supplied brief wording, explicit source copy requirements and disclaimers. Generated mandatory flags or a product reference naming the SKU cannot create exact required headline wording. The Copywriter authors and saves wording at its own stage; downstream instructions to use saved copy do not require pre-existing copy before drafting. Optional generated hero detail can be shortened or omitted, with explanatory text using only actually supported native/accompanying fields.
