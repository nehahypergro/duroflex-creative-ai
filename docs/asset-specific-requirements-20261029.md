# Asset-specific requirement intake — 29 October 2026

Shared across Duroflex and Sleepyhead. This pass captures assignments; it does not write copy or prescribe scenes.

- PDP: own website, Amazon or named other marketplace; no supplied template, an attached reference selected by ID, or an explicit template URL. Missing selected references remain visible errors. Existing same-brand reference admission still applies.
- Website/email: keep one current image or request desktop + mobile. The latter requires explicit mobile dimensions and produces two independent placement IDs, canvases and ordered delivery slots through the existing generation route. No universal mobile size is invented.
- A+: always-visible slot inventory uses the existing module contract, including desktop/mobile pairs and counts. Modules without separate mobile uploads say so explicitly.
- Print: existing physical preset determines the prominent flat-face/page count and fold note. A source selector distinguishes editable preset assumptions from supplied specifications; supplied specifications require an identifying reference. Existing trim, bleed, fold, shape and mounting controls remain.
- Retail screens: the same source distinction applies to the canvas/player requirements; existing orientation, crop, format, file limit and clearance controls remain.
- Promotions: all connected image recipes expose the inclusion choice. Offer-related text, an offer preset or a supplied offer surfaces exact wording, applicable SKU/variant, validity, start/end dates and conditions. Ongoing offers omit the end-date question. Explicit user choices override inferred inclusion. Excluded details remain saved for undoing a choice but are omitted from the generation handoff.
- QR/contact: none, QR, contact or both. QR requires an exact HTTP(S) destination; contact requires selected phone/address fields. Requirements capture is not a QR compositor or scan certification.
- Shared validation, saved drafts, reviewed requirement snapshots, unit counts and generation preparation use these controls. Old briefs without the new requirement contract retain their previous required fields.
