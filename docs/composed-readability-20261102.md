# Composed readability safeguards — 2 November 2026

New editable jobs pin composedQualityVersion 6. Versions 0–5 keep their existing prompts and gates; saved sources, frozen typography, reviews and receipts are preserved. Both brands use the same implementation and only their own pinned fonts/assets.

Before image dispatch, the existing reconciliation validates exact font fit and minimum displayed size, plus space around product/person envelopes, logo, other copy and canvas edges. Clearance is 0.2 em, minimum 2 canvas pixels. The real-font guide repeats the geometry test using Fabric measurements, including wrapped line count and allocated height. The planner is instructed to recompose scene/boxes/wrapping or use its existing copy/placement dependency when mandatory words cannot fit; no arbitrary word cap replaces measurement.

Typography checks reject unverified/light font weights, negative tracking, horizontal compression below 85%, and multiline leading below 1.1. Approved font families are unchanged; available regular/heavier faces must already belong to the scoped registry. These checks are proxies, not proof of glyph legibility. Existing placement-size checks and final visual review at the pinned viewing width remain necessary for actual stroke survival and crowded letterforms.

After reconstruction but BEFORE freezing and paid removal, local source pixels are checked around OCR lines, excluding the dilated glyph removal mask. Contrast uses each field's pinned minimum (default 4.5). A line fails above 10% low-contrast sampled pixels, or an eighth-line section above 25%; this prevents a narrow dark strip being hidden by a good average. Texture screening counts neighboring luminance jumps above 0.12 and flags an edge fraction above 18%. Insufficient samples remain unknown. Thresholds are versioned engineering heuristics, not calibrated human readability scores.

After removal, the same checks run over the clean background with no excluded pixels. This catches poor backgrounds hidden beneath source lettering or changed by repair. Failures stop final delivery; they do not alter frozen text or trigger an extra paid retry. Source/clean measurement reports are saved internally as composed-readability-{source|clean}-{unit}.json, bound to image hashes. Source, masks and clean backgrounds stay internal. Only final composed artwork is published.

Limitations: protected geometry is planned, not segmentation of every actual generated subject; final visual review still checks actual occlusion. Background masks can exclude a problematic patch before removal, making the clean-background gate essential. There is no guaranteed automatic rescue, perfect font recovery, or new paid review agent. Explicit user edits remain possible and retain ordinary unverified-edit behavior.
