## Changes

- Publishing-copy internal character targets are advisory. A 1,000-character field contract remains a bounded payload safeguard, not a publisher limit. No platform limits are invented.
- New publishing reviews return category, requirement and evidence. Blocking requirement IDs are restricted to claims, product identity, explicit brand/wording/language requirements and alt-text accuracy. Unrecognised or unevidenced blockers remain verification tasks. Suggestions can coexist with checked copy; uncertain copy stays unverified and is excluded from default checked-copy packages.

No customer-facing legacy-policy selector/version label was found in Studio's review projection; technical policy/history fields remain backend evidence and are not added to interface output.
