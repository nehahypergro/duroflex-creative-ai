# Simplified main-flow isolation audit — 6 November 2026

The new main Studio workflow remains: scoped brand/product preparation → one Astra medium communication/copy/spatial plan → two complete raster options (GPT Image 2 high and Sunburst high) → Luna medium conformance inspection → at most one evidence-directed correction candidate per option/page, followed by candidate inspection.

This audit fixes active legacy interference. It does not delete the implementation needed to open historical projects or recover their paid requests.

## Intentional shared code

Brand/product provenance, saved research, preference memory, format knowledge, strict output parsing, schema repair, image validation, transport recovery, job storage, cost accounting and independent queues remain shared. These are infrastructure and preparation boundaries, not additional creative reviewers. The lean planner resolves applicable guidebook advice once; image generation receives its compact execution brief.

The main flow reuses pure planner/review/correction contracts from the experiment module. It does not submit an experiment batch or use the old campaign planner, separate copywriter/art/layout stages, OCR, Fabric reconstruction, legacy scoring, PDP set review or carousel review.

Conformance inspection checks actual text, product identity, logo and applicable layout requirements. It is not aesthetic scoring. The correction candidate receives another inspection before selection; this is deliberate validation of changed artwork, not several competing reviewer systems. Uncertainty does not authorize a creative correction. Network/schema recovery remains bounded and recorded separately from the one creative correction allowance.
